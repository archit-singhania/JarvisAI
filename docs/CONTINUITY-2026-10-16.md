# Wednesday continuity studio — manual acceptance

Open Continuity studio in the browser or Windows assistant. Opening a panel never starts recording or executes a routine. Saved resources belong to your bearer workspace session; preserve its private client data to reopen them.

## Local meeting setup

Install `backend/requirements-meetings.txt` into your chosen Python environment. Provision a compatible faster-whisper model directory explicitly and set `WEDNESDAY_MEETING_MODEL` to its absolute path in the service process environment. Set `PYTHONPATH` to the absolute `backend` directory when starting the service from the repository root. No model download or installation occurs during recording/import. PyAV is pinned to 16.0.1 after validating real decoding. Use Python 3.11/3.12. The core remains usable without speech dependencies.

## Five acceptance journeys

1. **Routines:** Add ordered time/search/weather/assistant/reminder steps, conditions and stop/continue policies. Input references may point only backwards. Save and inspect Dry-run preview, then explicitly Run. Assistant/reminder steps pause for individual approval. Stop cancels remaining work. Inspect actual results; failures remain failed. Interrupted in-flight operations do not silently replay after restart. There are no arbitrary scripts or implicit messages.
2. **Branches:** Load a conversation, choose a saved message, name a branch and create it. Inspect the immutable parent comparison; continue in the independent branch. Its messages cannot replace parent history or silently modify global memories. Reload and check the branch relation remains saved.
3. **Meetings:** First try importing without participant consent: no job should be created. Confirm consent and import supported audio or explicitly record with the visible indicator/Stop control. Expect queued/processing/completed states and timestamped transcription from the installed local engine. Raw service audio is deleted only after successful transcript persistence unless retention was selected. Failed jobs retain audio for Retry/Delete. Save notes, decisions and proposed reminders, then reload. Creating an actual reminder still requires explicit review in Reminders. Importing never deletes the user's original file. Browser permission cancellation releases late streams; recorder startup failure releases microphone tracks.
4. **Digests:** Select individual conversations/reminders/approved receipts and generate a digest. Every item links to its source; unselected sessions remain excluded. Reload the saved snapshot. Both browser and native clients support durable daily/weekly local schedules with timezone and checked sources, plus on-demand generation. Coverage is explicitly partial when sources exceed collection bounds. Default summaries are deterministic; no live AI narrative is claimed.
5. **Layouts:** Save navigation/density presets for the current client and explicitly restore one. Unsaved message drafts remain intact, and recording/tools/permissions remain unchanged. Restoring a saved context validates ownership before selecting it. A missing context fails clearly; active meeting recording must be stopped before changing context.
